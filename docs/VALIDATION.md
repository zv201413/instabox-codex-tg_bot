| Python 语法、差异格式、凭据与运行文件检查 | 通过 |
| 真实 UID 999 VPS 安装、HTTPS/私网入口、TG 休眠唤醒 | 尚待部署后验收 |

无 root 部署测试覆盖自选端口、受保护配置文件、无系统时区数据库、启动钩子保留旧脚本及幂等更新、子进程失败重启、重复启动与优雅停止、PID 重用保护。它们在本地临时目录运行，不代表已在目标 VPS 启动。

Controller/Bridge 回归覆盖冷却、限流、持久化幂等请求、手动暂停、8 小时上限、消息去重、附件、会话、审批/表单、过期交互和安装时配置/状态保留。文件导出测试使用临时目录验证凭据目录与符号链接逃逸拦截，不要求本机存在云端目录。

运行：

```bash
sh tools/run_tests.sh all
```
