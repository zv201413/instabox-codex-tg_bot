## 成立的问题与修复

- 旧监督器因日志轮转等异常退出时，没有回收 Controller 子进程便删除身份记录。现在于 `finally` 中终止并等待子进程，优雅退出超时后强制结束，确认退出后再删除记录；清理期间保持排他锁。
- 旧钩子直接放在 shebang 后，早于脚本的环境初始化。现在按 `# INSTABOX_CONTROLLER_START` 明确标记插入，支持迁移旧钩子；已有脚本没有标记时拒绝写入。配置工具在创建凭据前先验证位置。

标记需要由用户放在脚本顶层环境初始化后、最终 `exec/exit` 前。安装器不解析完整 shell 控制流。监督器的清理覆盖正常停止和 Python 异常退出。
